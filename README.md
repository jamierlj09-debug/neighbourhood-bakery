# Crumb & Crust

A responsive, accessible one-page sample bakery website. Plain HTML and inline CSS, with an original inline SVG bread illustration; no dependencies or build step.

## Publishing
GitHub Pages serves `index.html` from the root of `main`.

## Personalise
Edit `index.html` to replace the sample bakery name, brand story and selection. Replace the clearly bracketed address, opening hours, email and phone placeholders with confirmed details. Remove the sample notice and labels once all details and menu/allergen copy have been checked.

No contact form, ordering system, analytics or backend is included.
